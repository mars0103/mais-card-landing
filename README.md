# MAIS Card

Landing page do MAIS Card.

## Rodar

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # gera dist/
npm run preview   # testa o build local
```

## Estrutura

- `index.html`: conteúdo da página
- `src/js/`: scroll, cena 3D e telas do app
- `src/styles/`: estilos
- `public/`: marca, imagens, páginas de termos e política
- `vercel.json`: rotas e cabeçalhos para a Vercel
